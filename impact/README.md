# Affected papers

The register covers 19 downstream works that use LaBRADOR or extend its projection analysis, and six optional or proposed configurations. The tables identify the affected bounds, parameter choices, and performance claims. References point to the linked papers unless another source is named. Page numbers use physical PDF pages unless printed pagination is also given.
